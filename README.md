# CropScan (Team Delta)

Detects leaf disease from phone photos with a fine-tuned ViT, then writes advice with GPT-4o vision.

**Requirements:** NVIDIA GPU with 24 GB VRAM (CUDA 12), `OPENAI_API_KEY`, and the PlantVillage dataset (not included: 2.1 GB).
Reported validation accuracy: 94.1% (see `train.py`; weights not included because of size).
No hosted demo: inference needs the GPU.
